# Древние Родословные Гномов — мод для Total War: WARHAMMER III

Механика родословных, как у вампиров, переделанная под гномов. Платить нужно **Клятвенным Золотом**, а качать роды можно **бесконечно**.

## Скачать

Готовый `dwf_ancient_lineages.pack` лежит во вкладке **[Releases → latest](../../releases/tag/latest)**.
GitHub собирает его автоматически при каждом изменении в `main`.

1. Скачайте `dwf_ancient_lineages.pack`.
2. Положите его в `…/steamapps/common/Total War WARHAMMER III/data/`.
3. Включите мод в лаунчере и начните или загрузите кампанию за гномов.

## Механика

| Род | Бонусы за уровень |
|---|---|
| **Гримнира** (воители) | +1 к атаке в ближнем бою, +2 к натиску |
| **Валайи** (хранители) | +1 к защите в ближнем бою; +1 к общественному порядку (до +30) |
| **Грунгни** (рудознатцы) | +3% к доходу; −2% к стоимости строительства (до −60%) |
| **Моргрима** (инженеры) | −2% к содержанию армий; −2% к стоимости найма (до −60%) |
| **Тунгни** (рунные кузнецы) | +2 к боевому духу, +2 к броне |

* Пробуждение рода стоит **80** Клятвенного Золота, каждый следующий уровень — `60 + 30 × уровень` (90, 120, 150…).
* Уровней **без ограничения**. Каждые 5 уровней наступает **Веха рода**: +10% ко всем бонусам этого рода.
* Атака, защита, натиск, броня, боевой дух и доход растут без предела. Процентные скидки (содержание, найм, строительство) и общественный порядок с каждым уровнем только приближаются к пределу, чтобы игра не сломалась.
* В интерфейсе кампании появляется **кнопка с наковальней**. При наведении она показывает уровни родов и цены, а по клику открывает окно выбора с ценой и бонусами следующего уровня.
* Мод работает в мультиплеере. ИИ-гномы могут тратить золото на роды (по умолчанию выключено).

Все числа настраиваются в блоке `CONFIG` и таблице `LINEAGES` в
[`mod/script/campaign/mod/dwf_ancient_lineages.lua`](mod/script/campaign/mod/dwf_ancient_lineages.lua).

## Структура репозитория

```
mod/                         исходники мода (повторяют структуру .pack)
  script/campaign/mod/…lua   логика
  db/<таблица>/…tsv          таблицы БД в формате TSV, как в RPFM
  text/db/…loc.tsv           русский текст
  ui/…                       иконки
tools/
  build_pack.py              сборка dist/*.pack (Python 3, без зависимостей)
  packlib.py                 запись и чтение форматов PFH5 / DB / LOC (по спецификации RPFM)
  schema_wh3_subset.json     схемы используемых таблиц WH3 (из rpfm-schemas)
  test_mod.lua               тесты логики скрипта с заглушками игрового API
.github/workflows/build.yml  CI: проверка Lua → тесты → сборка → релиз
```

Собрать локально:

```bash
python3 tools/build_pack.py
```

Прогнать тесты:

```bash
lua5.1 tools/test_mod.lua
```

## Что проверено, а что нет

* ✅ Синтаксис Lua и логика скрипта: уровни, цены, списание золота, страницы дилеммы, пределы, вехи, повторное применение бонусов после загрузки. Всё это покрыто тестами в CI.
* ✅ Структура `.pack` и таблиц соответствует формату RPFM и схеме WH3; после сборки пак читается обратно и сверяется с исходниками.
* ⚠ **В самой игре мод ещё не запускался.** Если что-то не работает, включите `debug = true` в `CONFIG`
  и посмотрите лог по префиксу `[DWF Ancient Lineages]` (нужен мод-логгер, например *Script Debug Activator*).
* ⚠ Ключи эффектов взяты из стандартных ключей WH2/WH3. Если какой-то ключ не найден, скрипт пропустит этот эффект и
  напишет об этом в лог, игра от этого не упадёт.
