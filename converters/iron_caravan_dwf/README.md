# Железный Караван для гномов (`iron_caravan_dwf.pack`)

Переделка мода `iron_caravan_draft` (караван наёмников чёрных гномов) под обычных гномов.
Исходный пак лежит только в приватном релизе `game-data`. В репозитории хранится лишь конвертер
[`convert.py`](convert.py): CI скачивает исходник, переделывает его, проверяет по данным игры и собирает `iron_caravan_dwf.pack`.

Нужен **MIXER** (`b_mixer.pack`). Оригинальный `iron_caravan_draft.pack` нужно **выключить**: у модов одинаковые файлы скриптов.

## Сделано

| Что | Как стало |
|---|---|
| Фракция | слот MIXER «Экспедиция Даина» (`mixer_dwf_dains_expedition`, лидер `1176379500`), культура и подкультура гномов. Стартовый генерал MIXER не трогается (у фракции стартовая орда-корабль «Дух Грунгни»), скрипт каравана сам заменяет его Рикартом |
| **Объединённые гномы: отряды** | в постройках каравана нанимаются **и** отряды чёрных гномов, **и** гномьи отряды с той же ролью. Лимиты отрядов чёрных гномов докупаются за Клятвенное золото (замена Адской кузницы из мода). Стартовая армия гномья |
| **Объединённые гномы: герои** | кастеляны, тауруки, Гордуз и (по правилам мода) колдуны чёрных гномов + все обычные гномьи герои. Постройки, открывающие кастеляна, открывают и инженера; открывающие таурука — и тана. Услуги героев каравана есть у обоих |
| Совместимость с модами на юнитов | список запрещённых отрядов убран; в слоты каравана можно строить обычные гномьи военные здания, поэтому отряды, которые другие моды добавляют в эти здания, появляются сами |
| Лорды каравана | Рикарт, Тордрек, генерал-кастелян, генерал-кентавр и новый «лорд каравана» (бывший надсмотрщик) — с гномьими моделями, навыками каравана. Обычные гномьи лорды — ванильные |
| Скуллкэннон | убран |
| Экономика | сырьё → **золото** (1 к 1), вооружение → **Клятвенное золото** |
| Бонусы построек | бонусы для стрелков/артиллерии/духа действуют и на чёрных, и на обычных гномов |
| Кузница | гномья кузница рун (у фракции гномья культура) + покупка лимитов отрядов чёрных гномов за Клятвенное золото |
| Технологии | пока обычное древо гномов |

## Следующие этапы

1. Технологии чёрных гномов и каравана — вкладкой в древе гномов.
2. Подгорода по образцу ковенов Нефераты: здания обороны, экономики, найма и влияния на регион; основывать может мастер-инженер (и Тордрек).
3. Зал героев в караване (лимиты героев).
4. 6 рунных слотов у всех героев фракции.
5. Кастомная кузница (`sxx_tiejiangpu`).
6. Вкладка прокачки героев в технологиях.
7. Русский текст для каравана (сейчас текст оригинала, местами про Хашута).
