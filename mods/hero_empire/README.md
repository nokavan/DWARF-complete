# Империя героев — отдельная фракция

Своя фракция `he_faction_hero_empire` со своей культурой `he_hero_empire` и подкультурой `he_sc_hero_empire`.
Основа — Империя. Столица — земли Хребта Сотека в Люстрии.

> ⚠ **Пока не для игры.** Фракции ещё нет в стартовой позиции: её нужно собрать в Assembly Kit (см. «Этапы»).
> Без неё пак только добавляет данные и ничего не меняет в игре.

## Что уже сделано (таблицы, генератор `_gen/gen_faction.py`)

* **Культура на основе Империи.** Всё, что игра выдаёт культуре и подкультуре Империи, скопировано для новой культуры.
  Сама Империя не меняется: участники групп кампании клонируются, а не правятся.
* **Свой набор построек** `he_bas_hero_empire`: копия имперского набора, Зал героев и 5 цепочек подворья.
* **Своё дерево технологий**: глубокая копия имперского набора узлов (89 узлов). Стартовая позиция, собранная
  в Assembly Kit, назначит его фракции.
* **Фракция**: строка на основе Рейкланда, флаг и цвета Хребта Сотека.
* **159 героев со всего мира.** Взяты все обычные герои игры: генерируемые, без лимита в 1, с правом носить предметы,
  у которых дерево навыков не привязано к чужой подкультуре. Уникальные и легендарные герои не входят.
  Ещё 5 обычных лордов Империи.
* **Зал героев** (`he_hall_of_heroes`, 3 уровня, только в столице). Открывает найм всех 157 героев, у которых в игре
  есть эффект открытия найма, и повышает лимит героев каждого типа на +1/+2/+3.
* **Рунные слоты**, как у гномов: 3 магических предмета (руны) на персонажа для всей фракции.
* **Подворья** перенесены из прототипа (`he_podvorye.lua`, `_gen/gen_data.py`).

Наборы внешности всех взятых героев не привязаны к культуре, поэтому модели будут работать.

## Этапы

1. ✅ Таблицы: культура, фракция, герои, Зал героев, руны, подворья.
2. ⏳ **Стартовая позиция**: исходные данные Assembly Kit (`assembly_kit/raw_data/db/start_pos_*`) → наша фракция с
   регионами Хребта Сотека и стартовой армией → сборка в Assembly Kit → `startpos.esf` в паке.
3. Своя механика Империи героев по дизайну: армии из героев, столица, ордена.

## Что не взято и почему

* 3 героя с деревом навыков только для своей подкультуры: Мурнгул, Глашатай гробниц, Лахмийская вампирша.
* Условия событий, наборы условий событий и наборы внешности Империи: если их клонировать, они могли бы сломать события самой Империи.

Прототип на базе Хребта Сотека лежит в `archive/hero_empire_sotek` и больше не собирается.
